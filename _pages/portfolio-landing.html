Martin Le

Wireless systems researcher and research software engineer, based in Dresden

I spent the last six years at the Institute for Communications Technology at TU Braunschweig, working on rate adaptation for Wi-Fi. A Wi-Fi device has to choose a data rate (modulation, coding, number of streams) for every transmission, and the right choice depends on a channel that keeps changing. I treat this as a multi-armed bandit problem and test the algorithms on real routers, not only in simulation.

I submitted my dissertation in August 2026; the defense date isn't set yet. Before the PhD I studied Information Systems Engineering at TU Dresden.

What I've worked on

WiFi-CUTS: rate adaptation with bandits

PhD work, 2019 to 2025

The main result of my PhD is WiFi-CUTS, a rate adaptation algorithm built on cascaded unimodal Thompson sampling. I compared it with Minstrel-HT, the default rate control in Linux, on IEEE 802.11ac hardware. Over the air it reached about 15% more throughput on average and at least 56% more in the first 0.7 seconds, when the algorithm is still learning. In simulations its average regret was at least 86% lower. It's published in IEEE Transactions on Communications.

The Wi-Fi testbed

TU Braunschweig

To run those experiments I set up and ran a testbed with commercial routers on OpenWrt, used both in shielding boxes and over the air. Most of the work was in the tooling: Python packages and APIs to set and read Wi-Fi parameters on Linux, checks on the data coming from the kernel to user space, and scripts that configure, run and evaluate an experiment without someone watching it. Part of this became the open-source resource control API we presented at ACM MobiCom 2024.

SupraCoNeX

BMBF-funded research project, 2020 to 2024

A joint project on using machine learning and bandit methods to improve Wi-Fi throughput, latency and robustness. I led Work Package 2, which meant coordinating the technical work, meetings, experiments and deliverables with the partners.

Indoor positioning from Wi-Fi CSI

Wireless Wanderlust competition, IEEE ISIT 2025

With two other doctoral researchers I built a semi-supervised positioning method from Wi-Fi channel state information: an autoencoder followed by a fully connected network that predicts the position, using several antenna arrays and frequency bands. We won the Junior Prize.
