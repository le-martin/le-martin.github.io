My research uses multi-armed bandits to choose transmission rates in Wi-Fi networks. I write the Python software and build the testbeds to evaluate these algorithms on real IEEE 802.11 hardware.

## About me

I'm an Information Systems Engineering graduate and PhD candidate working on wireless systems and machine learning. From 2019 to 2025, I worked as a research associate at Technische Universität Braunschweig.

Much of my work involves experiment automation: configuring routers, monitoring measurements, and building reproducible data pipelines. I evaluate algorithms in shielded RF chambers and over the air.

## Research & engineering

### Wi-Fi rate adaptation

Thompson Sampling and its variants (RAGTS, CTS, UTS, and CUTS) for IEEE 802.11ac rate adaptation, benchmarked against Minstrel-HT.

### Experimental testbeds

Automation and monitoring for experiments in shielded RF chambers and over-the-air deployments.

### Research software

Python tools to configure and monitor Wi-Fi systems, run experiments unattended, and deploy research algorithms on commercial routers.

## Selected work

### WiFi-CUTS

*2026, IEEE Transactions on Communications, vol. 74. Journal paper.*

Rate adaptation with cascaded unimodal multi-armed bandits, evaluated in an IEEE 802.11ac testbed. This is the core algorithmic contribution of my PhD. [Read the paper](https://doi.org/10.1109/TCOMM.2025.3628731)

### Wireless Wanderlust

*2025, IEEE ISIT. Junior prize, team of three.*

Semi-supervised indoor positioning from Channel State Information, using an autoencoder paired with a fully connected position predictor.

### Open Resource Control API

*2024, ACM MobiCom. Conference paper, co-author.*

Contributed to an open-source resource control API for real IEEE 802.11 networks, presented at ACM MobiCom with Sankalp P. Pawar and collaborators. [Read the paper](https://doi.org/10.1145/3636534.3697314)

### Event Management System

*2012, TU Dresden. Full-lifecycle software project.*

A web application for managing party events, with user accounts, a database, and calendar integration. The project covered design, implementation, testing, and client acceptance.

### Line-Following Robot

*2010, RoboLab. 1st place, team of four.*

A Lego Mindstorms robot that follows solid, dashed, curved, and zigzag lines while avoiding obstacles.
